# nem-time-series

Benchmarking time-series foundation models (starting with Amazon Chronos-2) on
Australian NEM electricity prices, then fine-tuning them.

Work in progress. Built step by step.

**Public data only.** Prices and demand come from AEMO's public MMSDM archive
(via `nemosis`); weather comes from the Open-Meteo historical forecast API.
No proprietary data is used.
